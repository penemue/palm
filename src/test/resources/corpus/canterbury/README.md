# Canterbury Corpus

This directory contains the complete Canterbury Corpus used for compression benchmarks.

Source: <https://corpus.canterbury.ac.nz/descriptions/>
Archive: <https://corpus.canterbury.ac.nz/resources/cantrbry.zip>

The corpus is intentionally stored unchanged so benchmark results remain comparable with published
Canterbury Corpus results.
